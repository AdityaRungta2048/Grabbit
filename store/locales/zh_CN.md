## Description
```
Grabbit 能在几秒内把任意网站变成整洁的表格。完全免费、无需账号，数据永远不会离开你的浏览器。

在网页上打开 Grabbit，它会自动找到列表和表格：商品、搜索结果、房源、名录、潜在客户、招聘信息、评论和价格。确认预览后，即可导出到 Excel、CSV、JSON 或 Google 表格。

★ 为什么选择 GRABBIT
• 100% 免费：没有点数、没有行数限制，也没有"升级后才能导出"
• 无需注册、账号或 API 密钥
• 隐私安全：全部在浏览器本地运行，不上传任何内容
• 无需代码：不用写选择器、XPath，也不用配置
• 权限极少：只读取你打开它的标签页，需要更多权限时会先询问

★ 功能
✔ 一键自动识别列表、网格和表格
✔ 点选模式：点击一个元素，自动选中所有相似元素
✔ 多页抓取：自动点击"下一页"按钮并翻页
✔ 无限滚动：持续滚动，收集所有条目
✔ 批量网址抓取：粘贴数百个链接或导入 CSV
✔ 定时抓取：每小时、每天或每周重新抓取，并显示新增行数。适合监控价格、库存和招聘信息。可自动下载 Excel 或 CSV
✔ 一键把所有图片批量下载到文件夹
✔ 提取邮箱、电话和社交主页（LinkedIn、X/Twitter、Facebook、Instagram、YouTube、TikTok、GitHub），还会检查联系页面
✔ 提取链接、图片和页面文本
✔ HTML 表格保留真实表头
✔ 内置编辑器：重命名和删除列、编辑单元格、去除重复
✔ 按网站保存抓取方案
✔ 导出到 Excel (.xlsx)、CSV、JSON、剪贴板或 Google 表格
✔ 侧边栏界面、快捷键 Alt+G、深色模式

★ 适用场景
• 获客：从企业名录收集邮箱和联系方式
• 电商：抓取商品、价格、评分和图片，监控竞品价格
• 房产、招聘和电商平台
• SEO：所有链接、标题和正文
• 研究与新闻：把 HTML 表格转成电子表格
• 招聘与营销

★ 使用方法
1. 打开任意网站，点击 Grabbit 图标（或按 Alt+G）
2. Grabbit 会高亮找到的数据。用 ‹ › 切换列表，或使用"在页面上选择"
3. 可选：开启"多页"或设置定时任务
4. 点击 Excel、CSV、JSON 或 Sheets，完成！

★ 隐私
Grabbit 没有服务器，不收集、不存储、也不出售任何数据。

请负责任地抓取数据，并遵守各网站的使用条款。
```
