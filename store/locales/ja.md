**Title (from the package):** Grabbit – 無料のWebスクレイパー＆データ抽出ツール

**Summary (from the package):** あらゆるサイトのデータをワンクリックでExcel・CSV・JSON・Googleスプレッドシートへ。無料、コード不要、登録不要。リスト・表・メールを抽出。

## Description
```
Grabbit は、どんなWebサイトも数秒できれいな表に変換します。無料・アカウント不要で、データがブラウザの外に送られることはありません。

ページで Grabbit を開くと、商品、検索結果、掲載情報、ディレクトリ、見込み客、求人、レビュー、価格などのリストや表を自動で見つけます。プレビューを確認して、Excel・CSV・JSON・Googleスプレッドシートに書き出すだけです。

★ GRABBIT が選ばれる理由
• 完全無料：クレジット制なし、行数制限なし、「エクスポートには有料プラン」もなし
• 登録・アカウント・APIキー不要
• プライバシー重視：すべてブラウザ内で処理し、何もアップロードしません
• コード不要：セレクタやXPath、設定は一切いりません
• 最小限の権限：開いたタブだけを読み取り、それ以上が必要なときは必ず確認します

★ 主な機能
✔ リスト・グリッド・表をワンクリックで自動検出
✔ ポイント＆クリック選択：1つクリックすると似た要素をすべて選択
✔ 複数ページ対応：「次へ」ボタンやページ送りを自動でたどります
✔ 無限スクロール対応：スクロールし続けてすべての項目を収集
✔ URL一括スクレイピング：数百のURLを貼り付けるか、CSVを読み込み
✔ スケジュール実行：1時間・1日・1週間ごとに再取得し、新しい行の数を表示。価格・在庫・求人の追跡に最適。ExcelやCSVの自動ダウンロードも可能
✔ 画像をワンクリックでフォルダに一括ダウンロード
✔ メールアドレス・電話番号・SNS（LinkedIn、X/Twitter、Facebook、Instagram、YouTube、TikTok、GitHub）を抽出。お問い合わせページも自動チェック
✔ リンク・画像・ページ本文の抽出
✔ HTMLの表は見出しをそのまま列名に
✔ 内蔵エディタ：列名の変更・削除、セル編集、重複削除
✔ サイトごとにレシピを保存
✔ Excel (.xlsx)、CSV、JSON、クリップボード、Googleスプレッドシートに出力
✔ サイドパネル、ショートカット Alt+G、ダークモード

★ こんな用途に
• 営業リスト作成：企業ディレクトリからメールや連絡先を収集
• EC：商品名・価格・評価・画像の取得、競合の価格モニタリング
• 不動産・求人・マーケットプレイス
• SEO：リンク、見出し、本文の一括取得
• リサーチや報道：HTMLの表をスプレッドシートに
• 採用・マーケティング

★ 使い方
1. サイトを開き、Grabbit アイコンをクリック（または Alt+G）
2. 見つかったデータがハイライトされます。‹ › でリストを切り替え、または「ページで選択」
3. 必要に応じて「複数ページ」やスケジュールを設定
4. Excel・CSV・JSON・Sheets をクリックして完了！

★ プライバシー
Grabbit にはサーバーがありません。データの収集・保存・販売は一切行いません。

スクレイピングは責任を持って行い、各サイトの利用規約を守ってください。
```
