# Spanish (es) listing

In the dashboard: **Store listing → language dropdown → Spanish**, then paste the description below.
The title and summary come from `_locales/es/messages.json` in the package automatically.

**Title (from the package):** Grabbit – Web Scraper gratis y extractor de datos

**Summary (from the package):** Extrae datos de cualquier web a Excel, CSV, JSON o Google Sheets en un clic. Gratis, sin código ni cuenta. Listas, tablas y emails.

## Description
```
Grabbit convierte cualquier sitio web en una hoja de cálculo limpia en segundos. Es gratis, no necesita cuenta y tus datos nunca salen de tu navegador.

Abre Grabbit en una página y encontrará las listas y tablas por ti: productos, resultados de búsqueda, anuncios, directorios, leads, empleos, reseñas y precios. Revisa la vista previa y exporta a Excel, CSV, JSON o Google Sheets.

★ POR QUÉ GRABBIT
• 100 % gratis: sin créditos, sin límite de filas y sin «mejora tu plan para exportar»
• Sin registro, sin cuenta y sin clave de API
• Privado: todo se ejecuta en tu navegador y no se sube nada
• Sin código: nada de selectores, XPath ni configuración
• Pocos permisos: Grabbit solo lee la pestaña en la que lo abres y pregunta antes de hacer más

★ FUNCIONES
✔ Detección automática con un clic de listas, cuadrículas y tablas
✔ Selector visual: haz clic en un elemento y Grabbit selecciona todos los parecidos
✔ Varias páginas: sigue los botones «Siguiente» y la paginación por ti
✔ Scroll infinito: sigue bajando y recoge todos los elementos
✔ Scraping masivo de URLs: pega cientos de enlaces o carga un CSV
✔ Scraping programado: repite la extracción cada hora, día o semana y ve cuántas filas son nuevas. Ideal para seguir precios, stock y empleos. Puede descargar Excel o CSV automáticamente
✔ Descarga masiva de imágenes en una carpeta con un clic
✔ Extractor de emails, teléfonos y perfiles sociales, también desde las páginas de contacto
✔ Extractor de enlaces, imágenes y texto de la página
✔ Las tablas HTML conservan sus encabezados reales
✔ Editor integrado: renombra y elimina columnas, edita celdas y quita duplicados
✔ Recetas guardadas por sitio web
✔ Exporta a Excel (.xlsx), CSV, JSON, portapapeles o Google Sheets
✔ Panel lateral, atajo Alt+G y modo oscuro

★ IDEAL PARA
• Generación de leads: emails y contactos de directorios de empresas
• E-commerce: productos, precios, valoraciones e imágenes, y seguimiento de precios de la competencia
• Inmobiliarias, empleos y marketplaces
• SEO: todos los enlaces, encabezados y textos
• Investigación y periodismo: tablas HTML a hojas de cálculo
• Reclutamiento y marketing

★ CÓMO FUNCIONA
1. Abre cualquier web y haz clic en el icono de Grabbit (o pulsa Alt+G)
2. Grabbit resalta los datos encontrados. Usa ‹ › para cambiar de lista o «Elegir en la página»
3. Opcional: activa «Varias páginas» o prográmalo
4. Haz clic en Excel, CSV, JSON o Sheets. ¡Listo!

★ PRIVACIDAD
Grabbit no tiene servidores. No recopila, guarda ni vende datos.

Por favor, haz scraping de forma responsable y respeta las condiciones de cada sitio web.
```
